# RTM — Derived Exposure Priors

This directory documents **deterministic building-level exposure features** for the Rotterdam (RTM) study area. They are spatial covariates/inputs for the research models; **they are not flood probabilities**. Their names as “priors” reflect historical project organisation, not Bayesian prior distributions.

## Data products and distribution status

### `building_water_proximity.parquet` — legacy, **local only**

- **Rows:** 221,324; stable join key: `bldg_id` (`int64`).
- **Actual schema:** derived exposure metrics **plus** retained OpenStreetMap building attributes.
- **OSM attribute columns:** `building`, `building:levels`, `building:height` (null typed in the inspected file), `height`, `building:material`, `roof:shape`, `roof:material`, `roof:height`, `roof:levels`, `name`, `addr:postcode`.
- **Derived fields:** `dist_to_water_m` (m), `water_len_density_250m`, `water_len_density_500m`, `water_len_density_1000m` (1/m).
- **Geometry:** no explicit geometry column; the records nevertheless contain third-party building attributes associated by ID.
- **Distribution:** excluded from the current Git index and retained locally. The source and rights review remain applicable; past Git history may still contain this file.

The previous README incorrectly described this file as containing *only* `bldg_id` and derived exposure variables. This section documents the **observed** schema instead.

### `building_water_proximity_v3.parquet` — reduced, versioned research product

- **Rows:** 221,324; stable join key: `bldg_id` (`int64`).
- **Actual columns:** `bldg_id`, `dist_to_hydrography_m`, `dist_to_coast_m`, `dist_to_water_m`.
- **Distance units:** metres.
- **Geometry:** no explicit geometry or coordinate columns.
- **Distribution:** retained in the current Git index for research reproducibility, **pending** a complete provenance and downstream-licence assessment. Absence of geometry does not automatically clear a building-level derived database for every form of republication.

## Inputs and processing

The earlier exposure product is documented as generated by:

- **Buildings:** `processed/RTM/derived/buildings_rtm.gpkg`, joined using `bldg_id`.
- **Hydrography:** `processed/RTM/derived/hydrography_rtm.gpkg`.
- **Generation script:** `scripts/rtm/compute_building_water_exposure.py`.
- **Working CRS:** EPSG:28992 (Amersfoort / RD New).

The building input is documented as **OpenStreetMap via Geofabrik Zuid-Holland**, acquired 18 January 2026 (see `raw/RTM/buildings/osm/SOURCE.md`); the original OSM dataset is under ODbL 1.0.

**Open source/provenance question:** the exact upstream hydrography source, original file/version, licence, and transformations require a final source-to-output check. Do not assume its identity solely from a candidate script or filename. The exact generation chain for `building_water_proximity_v3.parquet` should likewise be verified from the producing code and manifests.

## Interpretation and limitations

- One row per research building; `bldg_id` is an internal join identifier, not an external address or OSM ID.
- Distances and length densities are deterministic spatial exposure indicators, not Bayesian posterior probabilities and not predicted flood depths.
- Relative comparison and cross-city analysis require clearly documented scaling and population definitions.
- Derived metrics must be distinguished from original OSM tags when selecting material for distribution.

Conceptual definitions and assumptions: [RTM water exposure v0](https://github.com/Habnetic/docs/blob/main/references/exposure/rtm_water_exposure_v0.md).
